# مدير المناحل (Apiary Manager)

تطبيق Expo / React Native (TypeScript) لإدارة المناحل وجرد الخلايا، يعمل بدون إنترنت (SQLite)، بأربع لغات (العربية RTL، الفرنسية، الإنجليزية، الإسبانية).

## 1. هيكل المشروع

```
App.tsx                      نقطة البداية (قاعدة البيانات + اللغة + الموافقة على الإعلانات)
app.json / eas.json          إعدادات Expo وبناء AAB
src/i18n/                    إعداد i18next + locales/{ar,en,fr,es}.ts
src/db/database.ts           فتح SQLite وترحيل المخطط (migrations)
src/db/repo.ts               كل استعلامات المناحل والخلايا والسجلات والتقسيم والإحصائيات
src/db/backup.ts             تصدير/استيراد JSON
src/ads/                     AdBanner (بانر واحد فقط) + consent (UMP)
src/context/AppContext.tsx   اللغة، RTL، حالة إزالة الإعلانات
src/components/UI.tsx        أزرار كبيرة، حقول، Stepper للإطارات، شارات الحالة
src/screens/                 المناحل، الخلايا، التفاصيل، السجل، النسب، الإحصائيات، الإعدادات
src/config.ts                معرّفات AdMob ورابط سياسة الخصوصية (عدّلها)
```

## 2. التشغيل محلياً

```bash
npm install
npx expo install --fix        # يوائم الإصدارات مع نسخة Expo SDK المثبتة
npx expo prebuild --platform android
npx expo run:android          # هاتف حقيقي أو محاكي (يتطلب Android Studio)
```

- مكتبة الإعلانات ووحدة إعادة التحميل تحتاجان **Development Build**، لذلك لا تعمل الإعلانات داخل Expo Go. التطبيق نفسه يعمل في Expo Go بدون إعلانات.
- بدون Android Studio: `npm i -g eas-cli && eas login && eas build -p android --profile development` ثم ثبّت الـ APK وشغّل `npx expo start --dev-client`.

## 3. قبل النشر (إلزامي)

1. غيّر `android.package` في `app.json` إلى معرّف فريد خاص بك (لا يمكن تغييره بعد النشر).
2. أنشئ حساب AdMob، وأضف تطبيقك، ثم ضع **App ID** الحقيقي في `app.json` (plugin: react-native-google-mobile-ads) و**Banner Unit ID** في `src/config.ts`.
3. ضع رابط سياسة خصوصية حقيقياً في `src/config.ts` (يجب أن تذكر الإعلانات ومعرّف الإعلان وأن بيانات النحال تبقى على الجهاز).
4. استبدل `assets/icon.png` بأيقونتك (1024×1024).
5. اختبر دائماً بمعرّفات الاختبار (تُستعمل تلقائياً عندما `__DEV__`). لا تنقر على إعلاناتك الحقيقية أبداً.

## 4. بناء AAB

```bash
eas build -p android --profile production
```
ينتج ملف `.aab` يُرفع إلى Play Console. يدير EAS مفتاح التوقيع، ويُفضّل تفعيل Play App Signing.

## 5. خطوات Google Play Console

1. حساب مطوّر (رسم تسجيل لمرة واحدة).
2. أنشئ التطبيق، ثم ارفع الـ AAB إلى مسار Internal ثم Closed testing.
3. املأ: **Data safety** (المعرّف الإعلاني وبيانات الاستخدام التي يجمعها AdMob؛ بيانات المناحل لا تغادر الجهاز)، **Ads declaration** = نعم، **Content rating**، **Target audience** = بالغون (ليس موجهاً للأطفال)، وسياسة الخصوصية.
4. تحقق من شرط الاختبار للحسابات الشخصية الجديدة (عدد المختبرين ومدة الاختبار قبل الإنتاج)، فهو يتغير، راجع صفحة المساعدة الحالية.
5. تحقق من **مستوى API المستهدف** المطلوب حالياً. الحل: استعمل أحدث Expo SDK عند البناء.

## 6. التوافق مع سياسات AdMob

- بانر واحد فقط في شاشتي «المناحل» و«نظرة عامة»، ولا إعلانات في النماذج وإدخال البيانات.
- لا Interstitial ولا App Open في هذا الكود. لا تضفها لاحقاً في مسارات العمل الميداني.
- نموذج الموافقة UMP يظهر تلقائياً في أوروبا والمملكة المتحدة، وزر «خيارات خصوصية الإعلانات» في الإعدادات.
- لا تضع أزراراً قريبة جداً من البانر (الكود يتركه في أسفل الشاشة بعيداً عن أزرار الإجراء الرئيسية).

## 7. ترقية «إزالة الإعلانات»

الزر في الإعدادات يعمل في وضع التطوير فقط. للنشر يجب ربطه بـ **Google Play Billing** (السلع الرقمية تتطلب نظام الدفع الخاص بغوغل):
- الأسهل: RevenueCat (`react-native-purchases`) أو `react-native-iap`.
- أنشئ منتجاً غير قابل للاستهلاك `remove_ads`، وعند نجاح الشراء استدعِ `setPremium(true)` من `AppContext`، وعند «استعادة المشتريات» أعد التحقق منه.

## 8. اللغة واتجاه RTL

تبديل اللغة من الإعدادات. التحويل من/إلى العربية يقلب اتجاه الواجهة ويعيد تشغيل التطبيق تلقائياً (إن تعذّر، تُعرض رسالة لإعادة فتحه). استعمل `marginStart/paddingStart` بدل left/right عند إضافة واجهات جديدة.

## 9. قاعدة البيانات والنسب

- الجداول: `apiaries`، `hives` (حقل `parent_id` للنسب)، `logs`، `settings`.
- التقسيم يُنشئ خلية جديدة مرتبطة بالأم ويسجل العملية في معاملة واحدة.
- لتغيير المخطط لاحقاً أضف عنصراً جديداً إلى `MIGRATIONS` في `database.ts` ولا تعدّل القديم.
- النسخة الاحتياطية JSON تحتوي كل الجداول؛ الاستيراد يستبدل البيانات كلها داخل معاملة.
